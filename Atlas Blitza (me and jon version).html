Modding Guide

Mods are .js files — real JavaScript that runs inside the game. You have full access to every game variable, the DOM, and the Mod helper API. There are no limits and no sandboxing.

Drag or import a .js file from the welcome screen. Multiple mods stack — each one runs independently in the page. Refresh to reset everything.
Minimal mod
// Every mod gets a Mod object. Set your name first.
Mod.name = 'My Mod';
Mod.version = '1.0';

// Then write whatever you want.
Mod.toast('Hello from my mod!');
Mod API — Mod.*

The Mod object is your helper. Use it for convenience. Or ignore it and use the globals directly — your call.

Mod.name            // set your mod's name (string)
Mod.version         // set version string

// DOM
Mod.injectCSS(css)               // adds a <style> tag to <head>
Mod.injectHTML(html, selector)   // appends HTML inside a CSS selector

// Events
Mod.on('tick', fn)               // global RAF loop — fn({ time })
Mod.on('battleStart', fn)        // fn({ countries, manpower, military })
Mod.on('battleTick', fn)         // fn({ tick, manpower, rifles, territory, capitalFallen, countries })
Mod.on('battleEnd', fn)          // fn({ countries, manpower, territory })
Mod.off(event, fn)               // remove a listener

// Read game state
Mod.getState()                   // returns snapshot of live battle state

// Colors
Mod.hsl(h, s, l)                 // returns [r,g,b] — h/s/l all 0–1
Mod.hex('#rrggbb')               // returns [r,g,b]
Mod.rgb(r, g, b)                 // returns [r,g,b]
Mod.setColor(country, r, g, b)   // or setColor(country, [r,g,b])

// Flags
Mod.setFlag(country, url)        // URL or base64 data URI

// Time
Mod.freeze() / Mod.unfreeze() / Mod.toggleFreeze()
Mod.setSpeed(n)                  // 1=normal, 3=fast, 5=fastest

// Toast notification
Mod.toast('message', ms)         // ms optional, default 3500

// Military / missiles
Mod.setMilitary(country, { active, power })
Mod.setMissile(country, { vehicles, range, reload, warhead })

// Map CSS filter shorthand
Mod.setMapFilter('brightness(0.3) sepia(1)')

// Patch game variables by name
Mod.patch('unitSpeed', 2.0)      // see Game.* for all names

// Overlay text
Mod.setOverlay({ text, color, size, position })
// position: 'top-left' | 'top-right' | 'bottom-left' | 'bottom-right' | 'center'

// Cleanup on page close / reload
Mod.onUnload(fn)

// Console logging tagged with mod name
Mod.log('hello')
Game.* — direct game access

Game is a global object exposing every internal variable with full read/write access. Mutation is immediate — no helpers needed.

// Objects (mutate directly)
Game.CC                      // { "Germany": [r,g,b], ... } — country colors
Game.MIL_DB                  // { "Germany": { active, power }, ... }
Game.MISSILE_DB              // { "Germany": { vehicles, range, reload, warhead }, ... }

// Functions
Game.buildGeoCache()         // rebuild map after changing CC
Game.render()                // redraw map

// Live battle state (read-only intent; can write if you want chaos)
Game.bCurrentManpower        // [side0, side1] live troop counts
Game.bRifles                 // [side0, side1]
Game.bTerritoryRatio         // [side0, side1] — 0.0 to 1.0
Game.bCapitalFallen          // [side0, side1] — bool
Game.bFrame                  // simulation tick count
Game.bUnits                  // all live unit objects
Game.bInfluence              // Float32Array — influence grid
Game.selectedCountries       // [{ name, feat, ... }, ...]
Game.battleRunning           // bool

// Moddable constants (get and set freely)
Game.B_UNIT_SPEED            // default 1.1
Game.B_COMBAT_DMG            // default 1.6
Game.B_UNIT_HP               // default 70
Game.B_VICTORY_T             // default 120
Game.B_INF_BASE              // default 0.03
Game.B_OCCUPATION_REQUIRED   // default 1600
Game.PROD_PER_FACT           // default 3.5
Game.RIFLE_CONSUMPTION_PER_UNIT  // default 0.01
Game.FACT_CONFIRM_TICKS      // default 420
Game.FACT_REPAIR_ON_CAPTURE  // default 0.35
The variables above are also accessible directly as globals inside your mod — you don't need the Game. prefix. e.g. just write CC['Germany'] = [255,0,0].
Example — Rainbow colors (custom function)
Mod.name = 'Rainbow World';

// Run your own animation loop — full control over timing and math
Mod.on('tick', ({ time }) => {
  const t = time * 0.001;
  const countries = ['Germany', 'France', 'Japan', 'Brazil', 'India'];
  countries.forEach((c, i) => {
    Game.CC[c] = Mod.hsl((t * 0.2 + i / countries.length) % 1, 0.92, 0.55);
  });
  Game.buildGeoCache();
  Game.render();
});
Example — Inject CSS and custom UI
Mod.name = 'Night War';

// Completely restyle the game
Mod.injectCSS(`
  #map { filter: brightness(0.25) contrast(1.6) saturate(0.4) !important; }
  #battleHUD { background: rgba(0,0,20,0.97) !important; border-color: rgba(80,120,255,0.4) !important; }
  body { background: #000 !important; }
`);

// Add your own scoreboard
Mod.injectCSS(`
  #myScore {
    position: fixed; top: 80px; right: 16px; z-index: 500;
    background: rgba(0,0,20,0.9); color: #7bf; font-family: monospace;
    font-size: 12px; padding: 10px 14px; border-radius: 4px;
    border: 1px solid rgba(80,120,255,0.3); pointer-events: none;
    letter-spacing: .1em;
  }
`);
Mod.injectHTML('<div id="myScore">Waiting...</div>', 'body');

Mod.on('battleTick', ({ manpower, tick }) => {
  const el = document.getElementById('myScore');
  if (!el) return;
  const fmt = v => v >= 1e6 ? (v/1e6).toFixed(1)+'M' : v >= 1e3 ? (v/1e3).toFixed(0)+'K' : v;
  el.innerHTML = `TICK ${tick}<br>▲ ${fmt(Math.round(manpower[0]))}<br>▼ ${fmt(Math.round(manpower[1]))}`;
});
Example — Conditional trigger (when X happens, do Y)
Mod.name = 'Last Stand';
let fired = false;

Mod.on('battleTick', ({ manpower, territory, countries }) => {
  if (fired) return;
  // When side 1 drops below 30% territory...
  if (territory[1] < 0.30) {
    fired = true;
    Mod.toast('⚡ Last stand! Supercharging ' + countries[1]);
    // Give them a massive military boost
    Mod.setMilitary(countries[1], { active: 5_000_000, power: 99 });
    Mod.setMissile(countries[1], { vehicles: 30, range: 1500, reload: 60, warhead: 60 });
    // Flash their color red
    let flashes = 0;
    const iv = setInterval(() => {
      Game.CC[countries[1]] = flashes++ % 2 === 0 ? [255,30,30] : [200,200,200];
      Game.buildGeoCache(); Game.render();
      if (flashes > 8) clearInterval(iv);
    }, 200);
  }
});
Example — Stop time + step-by-step
Mod.name = 'Slowmo';

// Freeze the moment a battle starts
Mod.on('battleStart', () => {
  Mod.freeze();
  Mod.toast('Battle frozen — press ❚❚ to resume');
});

// Or control it yourself with a keypress
document.addEventListener('keydown', e => {
  if (e.key === ' ') {          // spacebar toggles freeze
    e.preventDefault();
    Mod.toggleFreeze();
  }
  if (e.key === 'ArrowRight') { // step one tick
    if (typeof bStep === 'function') bStep();
  }
});
Example — Custom flag from URL
Mod.name = 'Custom Flags';

// Replace any country's flag with any image
Mod.setFlag('Germany', 'https://upload.wikimedia.org/wikipedia/commons/thumb/b/ba/Flag_of_Germany.svg/320px-Flag_of_Germany.svg.png');
Mod.setFlag('France',  'https://upload.wikimedia.org/wikipedia/commons/thumb/c/c3/Flag_of_France.svg/320px-Flag_of_France.svg.png');

// Or paste a base64 data URI for a fully offline flag:

Example — Full chaos mod
Mod.name    = 'Chaos Mode';
Mod.version = '1.0';

// Warp the entire map aesthetic
Mod.injectCSS(`
  #map { animation: chaosHue 4s linear infinite; }
  @keyframes chaosHue { to { filter: hue-rotate(360deg) contrast(1.3); } }
`);

// Stamp an alt-history label onto the map
Mod.setOverlay({ text: '⚔ WW3 — 1987', color: '#ff4444', size: 18, position: 'top-left' });

// Supercharge every country equally
Object.keys(Game.MIL_DB).forEach(c => {
  Game.MIL_DB[c].active = 10_000_000;
  Game.MIL_DB[c].power  = 99;
  Game.MISSILE_DB[c] = { vehicles: 20, range: 2000, reload: 45, warhead: 80 };
});

// Hyper-fast battles
Game.B_UNIT_SPEED  = 3.5;
Game.B_COMBAT_DMG  = 4.0;
Game.B_OCCUPATION_REQUIRED = 300;

// Pulse all countries through a chaos rainbow on the map
let t = 0;
Mod.on('tick', () => {
  t += 0.003;
  Object.keys(Game.CC).forEach((c, i) => {
    Game.CC[c] = Mod.hsl((t + i * 0.07) % 1, 1, 0.5 + 0.1 * Math.sin(t + i));
  });
  Game.buildGeoCache();
  Game.render();
});
Tips
Direct game variable writes are permanent for the session. Refresh to reset everything to defaults.
You have full DOM access — addEventListener, fetch, localStorage, setTimeout, setInterval, canvas APIs, everything works.
Stack multiple mods by importing them one after another. Each runs in its own closure sharing the same game state.
Open the browser console (F12) to debug your mod. Mod.log() prefixes your console output with the mod name.
